# green-api-test

Веб-чат на React + TypeScript + Vite для работы с [GREEN-API](https://green-api.com/) (WhatsApp).

## Требования

- [Node.js](https://nodejs.org/) 20+ (рекомендуется LTS)
- npm (идёт вместе с Node.js)
- Аккаунт GREEN-API с активным инстансом

## Локальный запуск

1. Клонируйте репозиторий и перейдите в папку проекта:

```bash
git clone <url-репозитория>
cd green-api-test
```

2. Установите зависимости:

```bash
npm install
```

3. Задайте хост API в `.env`, если нужно переопределить значение по умолчанию. Хост вашего инстанса смотрите в личном кабинете GREEN-API:

```env
VITE_GREEN_API_HOST=<api-host>
```

4. Запустите dev-сервер:

```bash
npm run dev
```

5. Откройте в браузере адрес, который выведет Vite (обычно [http://localhost:5173](http://localhost:5173)).

6. На экране входа введите данные инстанса из [кабинета GREEN-API](https://console.green-api.com/). После успешной проверки откроется чат.

## Другие команды

| Команда | Описание |
| --- | --- |
| `npm run dev` | Dev-сервер с hot reload |
| `npm run build` | Сборка production в папку `dist` |
| `npm run preview` | Локальный просмотр собранного `dist` |
| `npm run lint` | Проверка ESLint |

## Как пользоваться

1. Войдите с данными инстанса GREEN-API.
2. В сайдбаре добавьте чат по номеру телефона (международный формат, без `+`, например `79001234567`).
3. Отправляйте текстовые сообщения; входящие подтягиваются через polling `receiveNotification`.

Данные сессии сохраняются в браузере. При выходе они удаляются.
